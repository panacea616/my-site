PORTFOLIO — PANACEA.GIF LINKS

This package keeps the existing monochrome portfolio layout and animation setup. The panacea.gif project modal now has two active links:
- Open the live app: https://panaceagif.netlify.app/
- Source code on GitHub: https://github.com/panacea616/panacea616gif

INSTALL
1. Back up your current portfolio folder.
2. Replace index.html, style.css, and script1.js with the files in this archive.
3. Copy img/panacea-demo.gif and img/panacea-poster.webp into your existing img folder. Keep your other images and fonts.
4. Refresh the site with Ctrl+F5 and open the panacea.gif project card.

The project-demo GIF is included in img/panacea-demo.gif. The app and repo links open in new tabs.
